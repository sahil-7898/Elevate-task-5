# Elevate-task-5

This is the readme Exploratory Data Analysis (EDA) on Titanic Dataset
This repository contains the analysis and findings from an Exploratory Data Analysis (EDA) performed on the Titanic dataset.

Objective
The goal of this task is to extract insights from the dataset using visual and statistical exploration, identifying trends, patterns, and anomalies.

Tools Used
Python (Pandas, Matplotlib, Seaborn)
Colab Notebook
Files
titanic_eda.ipynb: Colab Notebook with the full EDA process and visualizations.
EDA Steps
Statistical Exploration: Used .describe(), .info(), .value_counts() to understand data types, summary statistics, and distribution.
Visualization:
Pairplots and heatmaps to visualize relationships and correlations between variables.
Histograms, boxplots, and scatterplots to examine distributions and trends.
Findings: Written observations after each visualization, summarizing key insights.
Submission
This task was completed as part of the Data Analyst internship, and the repository contains the necessary code and report as per the task requirements.
